# 腾讯企业邮箱邮件操作

仅将本技能用于已配置的腾讯企业邮箱操作。随附的 Python 代码负责 SMTP 与 IMAP 操作；智能体负责规划操作、创建任务级规则、执行命令并报告结果。不得用临时编写的 SMTP/IMAP 代码替代随附脚本。

## 触发条件

在以下请求中使用：

- “给某人发送腾讯企业邮箱邮件”或“发企业邮件”。
- “查找/筛选/查看我的企业邮箱邮件”，包括按发件人、主题、日期、未读状态和附件制定规则。
- “总结这些符合条件的邮件”或“提取待办、金额、联系人或风险”。
- “下载符合条件邮件的附件”或“定时检查是否有新匹配邮件”。

不得用于其他邮箱服务商、不通过该邮箱发送的普通邮件文案，或没有指定账号与范围的“查看我的邮件”请求。遇到范围不清的请求，应先询问邮箱、筛选条件和期望结果。

## 必要工作流

1. 确定操作类型：`send`、`search`、`read`、`download` 或 `run-job`。执行前读取 [references/agent-workflow.md](references/agent-workflow.md)，其中规定了必填输入、准确命令、授权边界和预期输出。
2. 除非用户明确继续已有任务，否则创建一个任务工作区。在本技能根目录执行 `python scripts/create_workspace.py <任务名> --description "<需求范围>"`；后续只在生成的 `workspaces/<任务名>/` 中工作。
3. 将单次任务的筛选规则存入 `rules/`，将输出存入工作区规定位置。仅在新建或修改搜索/监控 JSON 文件时读取 [references/rule-schema.md](references/rule-schema.md)。
4. 只在任务工作区运行 `app/scripts/mail.py`。脚本会在加载凭据、连接邮箱或处理文件前检查整个 `workspaces/` 临时工作区的占用；默认阈值由 `config/workspace-policy.json` 的 `workspace_size_limit_mb` 控制，为 `500` MB。超限时除 `check-storage` 外的命令会安全停止，不写入结果、不连接邮箱。一次性需求不得修改 `core/`；仅当用户明确要求沉淀为通用能力时，才将已测试的改动提升至 `core/`。
5. 调用命令时，在子命令前使用 `--request-note "<脱敏的用户需求摘要>"`，并报告已执行的操作、属于预览还是实际执行、结果数量和生成的工作区相对路径文件。审计日志会记录中文时间、操作、调用功能、请求摘要、输入摘要、结果与错误；不得记录密码、原始密钥、密送地址或完整邮件正文。

## 授权与范围

- 发送、下载、覆盖文件和任何定时操作均属于外部副作用。执行实际命令前，确认用户当前请求已明确授权收件人或规则、正文或附件集合以及目标路径；确认后才使用脚本的确认参数。
- 只搜索和读取用户指定的邮箱目录与筛选条件。规则范围很宽时，拉取内容前先说明范围。只分析已返回的邮件；不得因为无关邮件可能有价值而扩大查询。
- 智能体不得主动要求用户在对话中粘贴凭据。用户自行提供邮箱地址和密码/客户端专用密码，并明确要求保存时，只能写入被忽略的本地 `config/config.json` 的 `account.email` 与 `account.password`；不得在回复、命令参数、日志、规则、工作区、聊天摘要或其他持久化记录中回显、复制或保留秘密。写入后只报告配置已更新。配置缺失或无效时，也可指导用户自行更新本地 `config/config.json` 或 `EMAIL_SKILL_PASSWORD` 环境变量。
- 默认下载到工作区 `downloads/`。工作区外路径必须由用户明确指定，并添加 `--allow-external-output`。

## 智能分析边界

执行 `search` 或 `read` 后，智能体只能总结筛选结果 JSON 或用户明确要求读取的完整正文。完整正文可包含纯文本、HTML 源码、HTML 转换后的可读文本及其他内联文本类型；附件仍按下载流程处理。必须说明总结依据是邮件头、正文预览还是完整正文。分析过程不得发送、下载、删除邮件或修改邮件状态。

用户要求查看附件内容时，先按下载预览和确认流程将**用户允许的附件**下载到当前任务工作区的临时目录 `downloads/attachments-reading/<本次读取名>/`，不得直接读取远程附件或把文件放到工作区外。下载后先检查当前项目和会话中是否存在适合该类型的读取 skill，并先完整读取所选 skill 的 `SKILL.md`：例如表格使用 `spreadsheets`，PDF 使用 `pdf`，Word 文档使用 `documents`。压缩包应先列出成员并阻止路径穿越、加密包和异常解压体积；只有用户明确指定成员后才解压该成员。若没有适用 skill，才在该临时目录生成最小读取脚本；纯文本或无法用脚本处理的内容可由模型直接读取。最终结果必须逐项标注读取来源：`引用 skill：<名称>`、`本次生成脚本：<路径>` 或 `模型自身识别`，并提示用户审核提取结果，尤其是金额、日期、公式、扫描件和压缩包内容。

## 异常处理

- 配置、认证、权限或网络失败：停止操作；说明不含敏感信息的错误类别和本地排查方式。不得自动重试。
- 规则格式错误、路径无效或必填输入缺失：不得使用更宽泛的替代规则。询问缺失值，或依照用户指示修正任务级规则。
- 零匹配结果：报告没有匹配邮件并保留规则与输出；未经授权不得扩大日期、关键词或目录范围。
- 附件冲突或跳过文件：报告被跳过的路径。除非已实现相应命令且用户明确要求，否则不得覆盖文件。
- 临时工作区超过阈值：不自动删除文件，也不跳过容量检查。除 `check-storage` 外停止命令；报告当前占用、阈值、可优先清理的 `downloads/`、`outputs/`、`logs/` 或 `drafts/` 中最大文件及其路径；请用户选择删除目标，或明确授权修改 `config/workspace-policy.json` 的阈值。
- 脚本出现未知错误：保留工作区产物并返回安全的错误输出；不得暴露配置内容。
