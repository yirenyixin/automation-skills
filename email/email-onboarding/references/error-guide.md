# 中文错误引导

| 错误类别 | 输出标记 | 建议 |
| --- | --- | --- |
| 配置文件缺失 | `【需要用户操作】` | 创建或填写该服务商的本地配置文件。 |
| 配置格式/字段错误 | `【配置失败】` | 检查 JSON 格式和缺少字段；不要展示秘密值。 |
| 认证失败 | `【配置失败】` | 检查客户端专用密码、QQ 授权码或 Gmail OAuth 令牌；不要自动重试。 |
| 服务权限不足 | `【需要用户操作】` | 引导用户在服务商后台启用对应客户端访问权限。 |
| 网络或服务器不可达 | `【配置失败】` | 检查网络、服务器地址和端口；等待用户明确要求后再测试。 |
| OAuth 已过期/撤销 | `【需要用户操作】` | 重新完成本地 OAuth 授权，不要改用账号密码。 |

初始化日志写入对应服务商 `logs/setup-audit.jsonl`，记录时间、服务商、步骤、状态、错误类别和下一步建议；绝不记录秘密或原始错误中可能包含的令牌。
