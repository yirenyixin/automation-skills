# 查询策略

通过 `--sql-file` 提供 SQL，通过 `--params-json` 提供参数。命名占位符的参数文件必须是 JSON 对象，位置占位符的参数文件必须是 JSON 数组。值由 MySQL 驱动绑定；不得将值插入 SQL 字符串。

仅允许一条 `SELECT` 或 `WITH ... SELECT` 语句。脚本会拒绝注释、DML、DDL、存储例程、锁定子句、`INTO OUTFILE`、`LOAD_FILE`、用户变量及任何非末尾分号。缺少 `LIMIT` 时会自动追加；已有的 `LIMIT` 必须是字面量，且不得大于 `--limit`。

对范围较大的查询，先运行 `explain`。估算仅供参考：即使使用索引的执行计划也可能返回敏感数据或超出预期的大量行。应保持筛选条件精确，并采用实际可用的最小限制值。
