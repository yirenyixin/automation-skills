# 受控变更策略

所有变更均由 Agent 保存为 SQL 文件并先执行 `preview`。预览创建带有效期的一次性确认记录，绑定 SQL 指纹、参数指纹、目标数据库和运行标识。

| 风险 | 示例 | 执行条件 | 回滚要求 |
| --- | --- | --- | --- |
| 低 | 结构读取、SELECT、EXPLAIN | 可直接执行 | 不适用 |
| 中 | INSERT、CREATE | 记录运行工件 | 推荐事务或补偿 SQL |
| 高 | UPDATE、DELETE、ALTER | 用户显式确认、`--commit` | 必须提供回滚 SQL |
| 极高 | DROP、TRUNCATE、GRANT、REVOKE | 用户显式确认、`--commit`、备份或人工恢复计划 | DDL 隐式提交时不能宣称可事务回滚 |

执行失败时，工具回滚未提交事务。提交后的恢复操作也必须重新预览并得到新的用户确认。审计日志只记录脱敏元数据、SQL/参数指纹、风险、耗时、状态和影响行数。
