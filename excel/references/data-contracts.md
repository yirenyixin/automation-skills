# 数据协议

## 工作簿 IR

`generate_xlsx.py` 接受如下 JSON。每个单元格可以是字符串、数字、布尔值、空值、ISO 日期字符串，或以 `=` 开头的 Excel 公式；数字、日期和公式都应使用原生单元格类型保存。

```json
{"sheets":[{"name":"汇总","freeze_panes":"A2","headers":["项目","金额"],"rows":[["销售额",1200],["成本",800],["利润","=B2-B3"]]}]}
```

工作表名必须唯一且不超过 31 个字符。`headers` 定义首行；`rows` 按顺序写入。不要让模型输出样式描述、坐标猜测或未声明的 Excel 对象。

## 模板数据

`fill_template.py` 只接收键值为标量的 JSON 对象，并替换文本单元格中的 `{{key}}`。循环、条件区块和图表数据绑定需要另行实现并测试。

## 检查结果

`inspect_xlsx.py` 输出工作表名、范围、公式和单元格值摘要。它不会计算公式；需要计算结果时必须在 Excel 或兼容引擎中复算并记录使用的引擎。
