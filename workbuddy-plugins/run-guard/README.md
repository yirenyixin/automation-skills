# WorkBuddy 运行防提前停止插件

本插件使用 Stop Hook 检查当前轮次。当同一轮出现真实工具失败，而模型最终只说“让我先……”“接下来我会……”或“继续执行”时，插件会阻止结束一次，并要求模型实际重试或明确报告失败。

## 设计目标

- 错误原因不得只留在折叠的深度思考中。
- 可修正的 shell、路径或参数错误必须实际重试一次。
- 无法安全重试时，必须显示失败阶段、退出码、原因和下一步。
- 使用 stop_hook_active 防止无限循环。
- 只分析本地会话转录，不调用额外模型，不上传内容。

## 临时验证

~~~powershell
codebuddy --plugin-dir "<插件目录>"
~~~

插件只对新会话生效。Windows 上的命令 Hook 由 Git Bash 执行，因此配置调用跨 shell 的 Node.js 脚本。若 WorkBuddy 桌面版当前未暴露插件安装入口，可先通过 CodeBuddy CLI 验证；单独导入 skill 只能提供规范，不能从宿主层强制阻止停止。
